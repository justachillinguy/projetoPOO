Detailed Description

Simulador continuo da Gestao de Fabrica.

Pressionar 'M' (ou 'm') pausa o simulador e abre o menu interativo. Pressionar 'Q' (ou 'q') termina o simulador. Cada passo representa 10 minutos simulados.
