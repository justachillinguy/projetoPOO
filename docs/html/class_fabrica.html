◆ PassoSimulacao()

void Fabrica::PassoSimulacao ( int minutoAtual,
int horaAtual,
int minutosPasso = 10,
double grausPasso = 2.0,
double arrefPasso = 1.5 )

Executa um passo de simulacao.

Por cada motor em START passa a RUN se a fabrica estiver aberta. Motores em RUN aquecem, acumulam tempo de trabalho e podem avariar. Motores em STOP arrefecem. O gestor e avisado quando um motor entra em AMARELO ou VERMELHO. Os sensores sao actualizados com o estado dos motores e a hora.

Parameters
minutoAtualMinuto do dia simulado (0-1439).
horaAtualHora simulada (0-23).
minutosPassoDuracao do passo em minutos simulados (default 10).
grausPassoAquecimento por passo em RUN (default 2.0).
arrefPassoArrefecimento por passo em STOP (default 1.5).
